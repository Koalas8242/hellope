## 项目解决什么问题

乡村体育教师通常同时承担体育课、大课间、课余训练、体质测试上报、器材管理，部分还要兼任其他学科或跨校走教。日常工作的真实困难集中在：

| 困难 | 具体表现 |
|---|---|
| **任务多而散** | 开学要交学期进度表，测试季要交体质数据，期末要交成绩和总结，平时还有教案、大课间方案、安全记录 |
| **条件受限** | 器材不足、场地简陋、复式班或大班额，城市学校的现成方案常常直接套不上 |
| **安全压力大** | 需要可执行的检查清单、预案和特异体质提醒，出了事也要有履职留痕 |
| **观摩资源分散** | 国家平台、省级教研、乡村专递、跨学科案例散落各处，看完就忘，难沉淀成自己的做法 |
| **职称佐证难积累** | 大课间、训练、测试、走教交通等工作量，平时不记，评优评先时说不清 |
| **网络和设备不确定** | 乡村学校网络不稳、电脑少，在线工具常打不开或要登录 |

本项目是一个**单文件、离线可用、手机可打开**的乡村体育教师工作台，把上述高频任务收进一个页面：能生成的直接生成，能打印的直接打印，能导出 CSV 的直接导出，能留痕的自动留痕。

**它不是**：在线教学平台、学生管理系统、体质评分官方工具。  
**它是**：你自己的日常工作效率工具，数据只存在你自己的浏览器里。

## 安装方法

### 1. 保存文件

复制程序全部代码，保存为：

```
乡村体育教师工作台.html
```

编码选 **UTF-8**。文件是单文件，不需要安装任何依赖。

### 2. 打开方式

| 设备 | 操作 |
|---|---|
| **电脑** | 双击文件，用 Chrome、Edge、360 等浏览器打开。无需联网、无需账号 |
| **安卓手机** | 发到微信“文件传输助手” → 手机上点开 → 选择“用浏览器打开”；或在浏览器菜单中“添加到主屏幕” |
| **iPhone** | 发到微信“文件传输助手” → 点开 → 右上角“…” → “用 Safari 打开”；Safari 分享菜单中“添加到主屏幕” |

### 3. 更新程序

用新文件替换旧文件即可。首次打开会自动把旧版 `v1` 数据迁移到 `v2`，不会丢失。

### 4. 数据位置

| 项 | 说明 |
|---|---|
| 存储方式 | 浏览器 `localStorage` |
| 新版键名 | `rural_pe_teacher_workbench_v2` |
| 旧版键名 | `rural_pe_teacher_workbench_v1`（仅用于首次迁移） |
| 是否上传 | **否**，不上传任何服务器 |
| 是否需要登录 | **否** |

## 使用方法

### 推荐上手顺序

```
首次使用 → 批量导入学生名单
        → 录入周课表
开学    → 生成学期教学进度表
日常    → 生成教案 / 大课间方案
测试季  → 打印现场记录表 → 录入 → 导出上报模板
平时    → 观摩 → 记可迁移策略 → 专业成长留痕
月末    → 导出工作量 CSV
期末    → 导出备份 JSON
```

### 分步说明

1. **首次使用**  
   进入“体质测试” → 展开“批量导入名单” → 粘贴全班名单，格式：
   ```
   姓名,性别,年级,班级,特异体质
   ```
   特异体质学生会自动在页面顶部提醒。

2. **录周课表**  
   进入“工作量” → 添加周课表项 → 以后每周点“一键生成本周工作量”，再手动补大课间、训练、走教交通。

3. **开学**  
   “教案/进度” → 生成学期教学进度表 → 打印或导出 CSV 交给教研组。

4. **日常备课**  
   “教案/进度” → 选年级、场地、器材、主教材、天气 → 生成教案 → 打印或保存。

5. **每天大课间**  
   “大课间” → 选主题和时长 → 生成方案 → 打印张贴或保存。

6. **测试季**  
   “体质测试” → 打印现场记录表 → 排队测试手写 → 回办公室录入 → 导出上报模板 CSV。

7. **观摩学习**  
   “观摩” → 按分类或关键词筛选 → 打开资源链接 → 看完点“记观摩笔记”，写下一条具体可迁移策略。

8. **月末/期末**  
   “工作量” → 导出 CSV；“工作台” → 导出备份 JSON。  
   **清理浏览器、换设备前务必先备份。**

### 快捷操作

| 操作 | 说明 |
|---|---|
| 删除记录 | 删除后 10 秒内可点“撤销删除”恢复 |
| 备份提醒 | 超过 7 天未导出备份，工作台顶部自动提醒 |
| 特异体质提醒 | 所有页面顶部自动显示，安排活动前先看一眼 |
| 批量导入 | 学生名单支持逗号、中文逗号、制表符分隔 |
| 打印 | 教案、进度表、大课间方案、现场记录表均有打印按钮 |
| CSV 导出 | 带 UTF-8 BOM，Excel 直接打开不乱码 |

## 输入输出示例

### 示例 1：生成一节教案

**输入**（“教案/进度”表单）：

```
年级：7年级        班级：1班        人数：40
场地：土操场/硬化地
器材：短绳20根、标志盘6个
主教材：跳绳
天气/条件：正常
复式班/大班额：勾选
```

**输出**（生成文本节选）：

```
【单课时教案】
年级/班级：7年级1班
人数：40    场地：土操场/硬化地    器材：短绳20根、标志盘6个
主教材：跳绳    天气/条件：正常
学习目标：
运动能力：80%以上学生能完成并脚跳、单脚交换跳与摇绳节奏；……

二、基本部分（28分钟）
1. 讲解示范（5分钟）：摇绳以腕为轴、前脚掌轻落地……
2. 分层练习（12分钟）：A组（基础）完成分解动作；B组（提高）完成组合动作……
3. 组合/简化比赛（8分钟）：30秒计数挑战、长绳“鱼贯而入”……
4. 体能补偿（3分钟）：平板支撑20秒×2组、原地高抬腿20秒×2组

复式班/大班额组织：A组（低年级/基础）做分解模仿和小组计数，B组（高年级/提高）
做组合练习并担任安全员；每6—8分钟轮换，教师定点巡回，小组长持任务卡。
```

### 示例 2：批量导入学生名单

**输入**（一行一个，逗号或制表符分隔）：

```
张三,男,7年级,1班,无
李四,女,7年级,1班,哮喘
王五,男,7年级,1班,无
```

**输出**：

- 学生名单新增 3 条
- 页面顶部出现提醒：`特异体质/免测提醒：李四（哮喘）。安排活动前请确认见习/免测要求，并在教案中标注。`

### 示例 3：体质测试录入与上报

**输入**：

```
学生：张三
身高：165 cm
体重：55 kg
肺活量：2800 ml
50米：8.2 秒
坐位体前屈：12.5 cm
立定跳远：190 cm
仰卧起坐：35 个
800米：4分20秒
```

**输出**：

- 记录保存，BMI 自动计算为 **20.2**
- 点击“导出上报模板 CSV”得到：

```csv
学籍号,姓名,性别,年级班级,学年,身高(cm),体重(kg),BMI,肺活量(ml),50米(秒),坐位体前屈(cm),立定跳远(cm),仰卧起坐(个),引体向上(个),800/1000米,等级(手填)
,张三,男,7年级1班,2026,165,55,20.2,2800,8.2,12.5,190,35,,4分20秒,
```

> BMI 仅作计算参考，正式评分请按《国家学生体质健康标准》对应年龄、性别评分表执行。

### 示例 4：工作量一键生成

**输入**（周课表）：

```
周一 第3节 七年级1班 体育课 40分钟
```

**输出**（本周工作量记录）：

```
日期           类型     分钟   备注
2026-10-26    体育课   40     七年级1班 第3节
```

“本月汇总”按类型累计分钟数，可导出 `工作量记录.csv` 用于绩效核算或职称材料。

### 示例 5：观摩笔记

**输入**：

```
关联资源：负重前行悟长征
可迁移策略：用书包作负重物，按能力分A/B两层，每层不同负重和圈数
打算用在哪里：五年级耐久跑
```

**输出**：

- 观摩笔记表格新增一行
- 可在“专业成长”中作为“观摩学习”佐证

## 数据与隐私

### 数据存储

| 项 | 说明 |
|---|---|
| 存储位置 | 本机浏览器 `localStorage` |
| 是否上传 | **否** |
| 是否需要登录 | **否** |
| 是否写 Cookie | **否** |
| 是否调用定位/摄像头/麦克风 | **否** |
| 是否有第三方脚本/统计代码 | **否** |

### 隐私提醒

1. **导出的 JSON/CSV 含学生姓名与身体数据**，请勿随意发群、上传公共网盘或发给无关人员。
2. **共用设备提醒**：页面顶部会显示特异体质学生姓名，办公室共用电脑或教室大屏投屏时注意屏幕隐私；演示或截图对外时，建议先清空或使用化名数据。
3. **清理浏览器数据、使用无痕模式、换设备前**，务必先导出备份 JSON；程序会在超过 7 天未备份时提醒。
4. **删除记录后 10 秒内**可点“撤销删除”恢复。

### 安全设计

- 所有用户输入写入页面前均经 HTML 转义
- 导入 JSON 采用白名单逐键复制，防止原型污染
- 外链均带 `rel="noopener noreferrer"`
- 无 `eval` / `new Function` / 动态脚本注入
- 无密码、token、API Key、本地绝对路径

## 常见问题

**Q：打开后是空白页？**  
A：确认文件编码为 UTF-8，用 Chrome/Edge 等现代浏览器打开。不要用 IE。

**Q：数据会不会丢？**  
A：数据存在本机浏览器。清理浏览器、换设备、无痕模式会丢。**定期导出备份 JSON** 是唯一可靠办法。

**Q：手机上字体太小/表格显示不全？**  
A：表格可左右滑动；建议横屏查看；也可在浏览器设置中调大字号。

**Q：能不能多台设备同步？**  
A：不内置同步。可通过“导出 JSON → 传到另一台设备 → 导入”手动同步。

**Q：体质测试能自动评分吗？**  
A：不能。BMI 只做计算参考，正式评分和等级请按《国家学生体质健康标准》对应评分表执行。

**Q：教案格式能直接交给教研组吗？**  
A：生成的是通用结构，各地教研室的固定模板可能不同，建议复制后按本地模板微调。

**Q：观摩链接打不开？**  
A：部分链接可能失效，可在全网搜索课例标题；第三方站点可能需注册或含广告，注意甄别。

**Q：旧版数据会丢吗？**  
A：首次打开新版会自动把 `v1` 数据迁移到 `v2`，并提示导出一次备份。
